# False Positive Control

False positives are usually caused by weak identity evidence, mixed galleries, broad search queries, or over-trusting provider ranking.

::: steps
1. Require brand and model evidence before considering a candidate.
2. Treat color evidence as mandatory for model-color workflows.
3. Prefer exact EAN and supplier SKU matches when available.
4. Penalize pages with many variants and weak selected-variant context.
5. Send uncertain candidates to review.
:::

## Review Useful Rejections

Rejected candidates are not waste. They are examples that improve trusted-source rules, thresholds, and provider choices.
